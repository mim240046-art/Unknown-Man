# Production release gates

A build is player-ready only when every gate is green on both editions.

1. Architecture/schema validation
2. Playable village and protected location graph
3. Survival foundation
4. Seven-day clock and checkpoints
5. Evidence journal and connections
6. Unknown Man perception and base AI
7. Scripted/random anomaly safety
8. Seven forms and animation/audio mapping
9. NPC system
10. Narrative puzzle framework
11. Cooking and sleep
12. Dynamic audio and atmosphere
13. Reversible village transformation
14. Skippable/recoverable cinematics
15. Four deterministic endings
16. Performance degradation and recovery
17. Java production hardening
18. Bedrock production hardening
19. Save migration, multiplayer, device compatibility
20. Accessibility, balance, QA, packaging, clean-install test

No demo, preview, prototype, or incomplete build may be labeled as the final player release.
